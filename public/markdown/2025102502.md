# 生命周期

vue有三个阶段，创建，更新，卸载，分别对应6个生命周期钩子函数

```js
import { onBeforeMount, onBeforeUnmount, onBeforeUpdate, onMounted, onUnmounted, onUpdated } from "vue";

//创建
onBeforeMount(() => {
  //无法访问dom
  console.log("创建之前=======>");
});
onMounted(() => {
  //可以访问dom
  console.log("创建之后=======>");
});
//更新
onBeforeUpdate(() => {
  //可以访问dom,访问到的是更新前的dom
  console.log("更新之前=======>");
});
onUpdated(() => {
  //可以访问dom,访问到的是更新后的dom
  console.log("更新之后=======>");
});
//卸载,卸载组件的操作可以通过使用v-if来进行卸载
onBeforeUnmount(() => {
  console.log("卸载之前=======>");
});
onUnmounted(() => {
  console.log("卸载之后=======>");
});
```

除此之外还有4个生命钩子函数分别是，beforeCreate,created(使用setup就没有前两个生命周期),onRenderTracked,onRenderTriggered(这两个生命周期钩子函数是用来调试的，他会在组件中内容被修改时返回一个effect事件)
