# 原型链

原型链是 JavaScript 实现继承（Inheritance）的核心机制。有两个核心的概念：prototype（原型对象）,_ _proto__

_ _proto__作为链条链接着prototype，每个函数都有prototype，prototype是给子类提供共享属性的。由于prototype是一个对象。每个对象默认有着一个proto的属性，指向这个对象的构造函数的prototype（即实例.proto === 构造函数.prototype），以此形成链条，当这个实例的prototype中没有所需的属性时候就通过proto向父级的prototype寻找知道找到null（即Object.prototype.proto）
